# Как помочь проекту

Спасибо за интерес к AlikDrone Hub. Мы приветствуем отчёты об ошибках, идеи и pull request.

## Перед созданием issue

1. Проверьте, что используете последнюю BETA-версию.
2. Убедитесь, что похожая проблема ещё не описана.
3. Уберите из скриншотов и отчётов серийные номера, координаты, SSID, IP/MAC, токены и личные файлы.

## Проверка изменений

Требуются JDK 17 и Android SDK Platform 30.

```powershell
.\gradlew.bat --no-daemon testGithubUnitTest lintGithub assembleGithub
```

Не добавляйте APK/XAPK, keystore, пароли, токены и приватные материалы. Изменения каталога должны сохранять контроль размера, SHA-256 и отпечатка подписи.

Pull request должен описывать причину изменения, влияние на пользователя и выполненные проверки. Не включайте в один PR несвязанные правки.
