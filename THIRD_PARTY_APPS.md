# Сторонние приложения

APK/XAPK сторонних приложений не входят в исходный код AlikDrone Hub и не распространяются по GPL-3.0 вместе с ним. Названия, логотипы и товарные знаки принадлежат соответствующим правообладателям. AlikDrone Hub не является официальным клиентом или партнёром перечисленных сервисов.

Публичная GitHub-версия Hub показывает восемь популярных приложений:

| Приложение | Ожидаемый пакет | Формат |
|---|---|---|
| Telegram | `org.telegram.messenger.web` | APK |
| Discord | `com.discord` | XAPK |
| YouTube | `com.google.android.youtube` | APK |
| RUTUBE | `ru.rutube.app` | APK |
| Cromite | `org.cromite.cromite` | APK |
| Happ | `su.happ.proxyutility` | APK |
| SHAREit | `com.lenovo.anyshare.gps` | APK |
| Windy | `com.windyty.android` | APK |

Файлы загружаются с зеркала `alik-drone.ru`. Для каждой записи в исходном коде закреплены ожидаемые package name, versionCode, SHA-256 файла и SHA-256 сертификата подписи. Hub повторно проверяет эти значения перед установкой. Совпадение контрольных данных защищает от незаметной подмены зеркала, но не является независимым аудитом безопасности самого приложения.

Устанавливайте стороннее ПО на свой риск и проверяйте запрашиваемые им разрешения. Telegram и Discord на пульте могут работать нестабильно; рекомендуется отключить их уведомления. SHAREit запрашивает широкий набор разрешений — устанавливайте его только при реальной необходимости.

Если вы правообладатель и хотите сообщить о зеркале или названии, используйте порядок из [SUPPORT.md](SUPPORT.md).
