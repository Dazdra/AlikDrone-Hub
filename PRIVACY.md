# Конфиденциальность

AlikDrone Hub работает без учётной записи и не содержит собственной аналитики, рекламных SDK или автоматической отправки отчётов поддержки.

## Какие данные используются локально

На пульте могут храниться:

- настройки и положение Taskbar;
- категории и видимость найденных приложений;
- ссылка Android на выбранную пользователем папку APK;
- локальный индекс выбранных KML/KMZ-файлов;
- записи журнала обслуживания, которые пользователь вводит вручную;
- служебное состояние загрузок Android Download Manager.

Эти данные нужны для работы функций Hub и не синхронизируются с облаком AlikDrone.

## Сеть

Hub использует сеть для загрузки APK/XAPK публичного каталога с зеркала `alik-drone.ru` и для открытия выбранных пользователем внешних сайтов. Обычный сетевой запрос раскрывает серверу назначения IP-адрес и стандартные технические данные соединения. Hub не добавляет к этим запросам серийный номер пульта, координаты, SSID, содержимое файлов или токены пользователя.

Внешние сайты и установленные сторонние приложения действуют по собственным правилам конфиденциальности. AlikDrone Hub не управляет их сбором данных.

## Файлы

Hub получает доступ только к файлам и папкам, которые пользователь выбрал в системном окне Android. Приватный каталог DJI Fly недоступен обычному APK. Удаление файла возможно только после отдельного действия и подтверждения пользователя в интерфейсе Hub.

## Отчёт поддержки

Отчёт создаётся локально и сначала показывается для проверки. Он не отправляется автоматически. Копирование в буфер обмена и системное меню «Поделиться» запускаются только кнопками пользователя.

Из отчёта всегда исключаются серийный номер, координаты, SSID, IP/MAC, токены, личные файлы и содержимое логов. Перед публикацией всё равно проверьте предпросмотр и снимите ненужные разделы.

## Удаление данных

- сохранённый доступ к папке можно отозвать в Hub;
- отдельные записи библиотеки и журнала удаляются в соответствующих экранах;
- удаление Hub очищает его локальные данные, поскольку резервное копирование приложения отключено;
- APK в общей папке `Download` и сторонние установленные приложения после удаления Hub остаются — удалите их отдельно при необходимости.

Подробнее о системных доступах: [docs/PERMISSIONS.md](docs/PERMISSIONS.md).
