# Security Policy

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней опубликованной BETA-версии. Проверяйте её на странице [Releases](https://github.com/Dazdra/AlikDrone-Hub/releases).

## Подпись релизов

Начиная с `1.5.18-beta`, APK подписывается постоянным ключом AlikDrone Hub.

SHA-256 сертификата:

```text
80:A5:29:FB:8D:53:63:02:B7:6C:27:2B:DF:99:01:EE:12:86:20:84:5E:0A:A1:2A:B4:9B:71:6A:E9:14:BB:9E
```

SHA-256 самого APK публикуется в `SHA256SUMS.txt` каждого релиза. GitHub Actions также создаёт provenance attestation для релизного APK.

## Сообщение об уязвимости

Не публикуйте уязвимости, токены, персональные данные и приватные отчёты в открытых issues.

Если проблема позволяет скрытую установку, раскрывает данные пользователя или влияет на безопасную работу пульта, сначала сообщите о ней владельцу проекта через контакты на [alik-drone.ru](https://alik-drone.ru/). После исправления можно создать публичное описание без чувствительных деталей.

В сообщении укажите версию Hub, модель и прошивку пульта, сценарий воспроизведения и возможное влияние. Первичное подтверждение получения ожидается в течение 7 дней; сроки исправления зависят от тяжести и воспроизводимости проблемы.
