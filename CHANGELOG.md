# Changelog

## 1.5.18-beta — 2026-08-01

### Сделано

- добавлена единая инструкция установки для подготовленного и сброшенного DJI RC 2;
- документированы разрешения Android, приватность, обновление, удаление и откат;
- добавлена таблица решения типовых ошибок установки и загрузки;
- публичные релизы переведены на постоянную подпись AlikDrone Hub;
- APK релиза теперь собирается GitHub Actions из соответствующего тега;
- добавлены SHA-256, provenance attestation и архив точных исходников релиза;
- усилена автоматическая проверка зависимостей и GitHub Actions.

## 1.5.17-beta — 2026-08-01

Первая публичная BETA-версия AlikDrone Hub.

### Добавлено

- публичный каталог Telegram, Discord, YouTube, RUTUBE, Cromite, Happ, SHAREit и Windy;
- проверка загрузок по закреплённым размеру, SHA-256 и отпечатку подписи;
- AlikDrone Taskbar с сеткой, порядком, категориями и скрытием приложений;
- FlightRecord Export, файлы пульта, KML/KMZ-задания, Web Tools и журнал обслуживания;
- информация о пульте и очищаемый отчёт поддержки.

### Исправлено

- обнаружение приложений, установленных до AlikDrone Hub;
- обновление Taskbar после установки и удаления приложений;
- дублирование и неверное сопоставление иконок в панели быстрого запуска;
- восстановление положения Taskbar после перезапуска.

### Ограничения BETA

- APK подписан тестовым Android-ключом;
- совместимость подтверждена только на DJI RC 2, DJI RC Pro 2 и DJI RC Plus 2 Enterprise;
- работа сторонних приложений зависит от Android, прошивки пульта и наличия сервисов Google;
- сторонние APK/XAPK не проходили независимый аудит AlikDrone.
