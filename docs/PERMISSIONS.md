# Разрешения AlikDrone Hub

Hub не получает root-доступ и не обходит ограничения Android. Установка и удаление передаются системным компонентам и всегда требуют подтверждения пользователя.

## Разрешения из AndroidManifest

| Разрешение | Для чего используется |
|---|---|
| `INTERNET` | Загрузка приложений публичного каталога и открытие выбранных пользователем веб-ресурсов. |
| `ACCESS_NETWORK_STATE` | Показ состояния сети и доступности интернета без чтения SSID, IP или MAC. |
| `REQUEST_INSTALL_PACKAGES` | Передача APK/XAPK штатному Package Installer. Не разрешает скрытую установку. |
| `REQUEST_DELETE_PACKAGES` | Открытие штатного окна удаления выбранного приложения. Удаление подтверждает пользователь. |
| `SYSTEM_ALERT_WINDOW` | Необязательная плавающая панель Taskbar поверх других приложений. |
| `RECEIVE_BOOT_COMPLETED` | Восстановление Taskbar после перезагрузки, только если пользователь ранее включил его. |
| `FOREGROUND_SERVICE` | Работа включённого Taskbar как видимого системного сервиса с уведомлением. |

## Специальные доступы Android

### Неизвестные источники

Android выдаёт доступ отдельно каждому источнику:

- приложению «Файлы» — чтобы установить Hub с microSD;
- AlikDrone Hub — чтобы передать выбранное приложение системному установщику.

Разрешение можно отозвать в системных настройках Android. После отзыва Hub продолжит работать, но не сможет начинать установку APK.

### Поверх других приложений

Доступ нужен только для Taskbar. Если его не выдавать, остальные функции Hub продолжат работать. Taskbar можно отключить в Hub и отозвать доступ в системных настройках.

### Выбранные файлы и папки

Hub использует системный Storage Access Framework. Доступ появляется только после выбора пользователем конкретного APK, KML/KMZ-файла или папки. Hub не запрашивает широкое разрешение на всё хранилище и не получает доступ к приватным каталогам DJI Fly.

Сохранённый доступ к папке APK можно удалить кнопкой «Отключить папку» в Hub.

## Видимость приложений

Hub запрашивает у Android список запускаемых приложений и сведения о нескольких известных пакетах, чтобы показать установленные программы, их версии и иконки. Это не даёт доступа к содержимому или аккаунтам этих приложений.

## Разрешения, которых нет

Hub не запрашивает доступ к геопозиции, камере, микрофону, контактам, SMS, звонкам или календарю.

Системный Package Installer загружается отдельно по [официальной ссылке AlikDrone](https://alik-drone.ru/rc2/alikdrone-rc2-installer.apk), не входит в этот Git/GPL-репозиторий и имеет собственный набор системных возможностей.
