# Установка AlikDrone Hub

AlikDrone Hub находится в статусе **BETA**. Устанавливайте его на земле, без подключённого дрона. Во время полёта и обновления прошивки не запускайте сторонние приложения и Taskbar.

Hub не использует root и не устанавливает приложения скрытно. Каждую установку или удаление подтверждает пользователь в системном окне Android.

## Что скачать

- из последнего [GitHub Release](https://github.com/Dazdra/AlikDrone-Hub/releases) — файл `AlikDrone-Hub-1.5.19-beta.apk`;
- для чистого или заблокированного пульта — [системный Package Installer](https://alik-drone.ru/rc2/alikdrone-rc2-installer.apk).

Не скачивайте `*-source.zip` для установки: это архив исходного кода.

Системный установщик — отдельный компонент. Он не входит в этот Git/GPL-репозиторий и не распространяется по GPL вместе с AlikDrone Hub. Полная инструкция находится на [alik-drone.ru/hub](https://alik-drone.ru/hub/).

Параметры проверенного файла по указанной выше ссылке:

```text
Package: com.android.packageinstaller
Version: 11 (versionCode 30)
Размер: 3 274 224 байта
SHA-256: 523361ACBE62587FA61E00A92369E87DAA0D812232B8942DEBA67771CCF2633A
SHA-256 сертификата: A4AA1CDD2EA580CBBE67486B5F6F3CFEA83F488889995AFA70793DAA516687DA
```

Если размер или SHA-256 загруженного установщика отличаются, не открывайте его и сообщите об этом через [SUPPORT.md](../SUPPORT.md).

## Подготовка microSD

1. При необходимости сохраните файлы с карты: форматирование удалит их.
2. Отформатируйте microSD средствами пульта.
3. Подключите карту к компьютеру и откройте папку `Download` в корне карты. Если папки нет, создайте её.
4. Скопируйте нужные APK точно в `microSD:/Download/`.
5. Безопасно извлеките карту и верните её в пульт.

На пульте откройте уведомление о карте кнопкой «Обзор» либо запустите штатное приложение «Файлы», затем перейдите в `SD-карта → Download`.

## Сценарий A: пульт уже подготовлен

Используйте этот сценарий, если при открытии APK появляется обычное системное окно установки Android.

1. Скопируйте `AlikDrone-Hub-1.5.19-beta.apk` в `microSD:/Download/`.
2. Откройте файл через «Файлы».
3. Если Android блокирует неизвестный источник, нажмите «Настройки», разрешите установку **для приложения «Файлы»** и вернитесь назад.
4. В системном окне нажмите «Продолжить», если оно показано, затем «Установить».
5. После сообщения «Приложение установлено» откройте AlikDrone Hub.

## Сценарий B: чистый или заблокированный пульт

Используйте этот сценарий, если пульт пишет, что пользователю не разрешено устанавливать приложения, либо системный установщик отсутствует или не открывается.

1. Скопируйте в `microSD:/Download/` два файла:
   - `alikdrone-rc2-installer.apk`;
   - `AlikDrone-Hub-1.5.19-beta.apk`.
2. Через «Файлы» сначала откройте `alikdrone-rc2-installer.apk`.
3. При запросе неизвестного источника разрешите установку **для приложения «Файлы»**, вернитесь назад и подтвердите установку или обновление Package Installer в системном окне.
4. Дождитесь сообщения об успешной установке. Если прежнее ограничение сохранилось, полностью перезагрузите пульт.
5. Только после Package Installer откройте `AlikDrone-Hub-1.5.19-beta.apk` и подтвердите установку Hub.

Не меняйте порядок: **сначала Package Installer, затем Hub**.

## Отдельное разрешение для Hub

Разрешение неизвестного источника выдаётся каждому приложению отдельно. Разрешение для «Файлов» не разрешает Hub устанавливать приложения каталога.

При первой установке приложения из Hub:

1. нажмите в Hub «Разрешить установку»;
2. включите «Разрешить установку из этого источника» для **AlikDrone Hub**;
3. вернитесь в Hub;
4. снова нажмите «Установить» и подтвердите действие в системном окне Android.

Разрешение «Поверх других приложений» требуется только для Taskbar и не связано с установкой APK. Подробнее: [PERMISSIONS.md](PERMISSIONS.md).

## Проверка версии

После запуска в верхней части главного экрана должно быть указано:

```text
Версия Hub: 1.5.19-beta
```

Идентификатор приложения в системных настройках: `ru.alikdrone.hub`. Контрольную сумму APK сверяйте со значением в описании GitHub Release.

Если отображается `1.5.17-debug` или `1.5.17-github`, установлена старая BETA-сборка с тестовой подписью. Перед переходом на `1.5.18-beta` или более новую версию её нужно удалить один раз. `1.5.19-beta` устанавливается поверх `1.5.18-beta` без удаления приложения.

## Обновление и удаление

Обновление с той же подписью устанавливается поверх текущей версии. При конфликте подписи или откате на более старую версию Android может потребовать удалить Hub. Перед удалением отключите Taskbar; локальные настройки Hub будут удалены, а установленные через него сторонние приложения останутся.

Решения частых проблем и порядок отката: [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
