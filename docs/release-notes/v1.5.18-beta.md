# AlikDrone Hub 1.5.18 BETA

Публичная BETA с исправленной системой обновлений и полноценной документацией установки.

## Что изменилось

- релизы переведены на постоянную подпись AlikDrone Hub;
- APK собирается из тега GitHub Actions, а не загружается вручную;
- добавлены SHA-256 и provenance attestation релизного APK;
- описана установка как на подготовленный, так и на чистый/сброшенный DJI RC 2;
- добавлены инструкции по разрешениям, обновлению, удалению и откату;
- добавлены приватность, поддержка и таблица решения типовых ошибок;
- усилена автоматическая проверка зависимостей и GitHub Actions.

Функциональность Hub и публичный каталог приложений соответствуют `1.5.17 BETA`.

## Важно при обновлении с 1.5.17

Сборки `1.5.17-debug` и `1.5.17-github` были подписаны тестовым ключом. Перед первой установкой `1.5.18-beta` их нужно удалить. Это одноразовая миграция: следующие версии с постоянной подписью будут обновляться поверх `1.5.18-beta`.

Перед удалением старой версии отключите Taskbar. Настройки старой версии могут быть потеряны.

## Установка

Обычному пользователю нужен только файл `AlikDrone-Hub-1.5.18-beta.apk`. `Source code` и `*-source.zip` на Android не устанавливаются.

- Если установка APK уже работает — скопируйте Hub в `Download` на microSD и откройте его на пульте.
- Если пульт сброшен или запрещает установку — сначала установите [системный установщик](https://alik-drone.ru/rc2/alikdrone-rc2-installer.apk), затем Hub.

Полная инструкция: [docs/INSTALL.md](https://github.com/Dazdra/AlikDrone-Hub/blob/main/docs/INSTALL.md).
