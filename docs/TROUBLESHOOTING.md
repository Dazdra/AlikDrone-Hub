# Решение проблем

Сначала убедитесь, что используете APK из последнего [GitHub Release](https://github.com/Dazdra/AlikDrone-Hub/releases), а не архив `*-source.zip`.

## Пульт запрещает устанавливать приложения

Если появляется сообщение «этому пользователю не разрешено устанавливать приложения» или не открывается системное окно:

1. скачайте [системный Package Installer](https://alik-drone.ru/rc2/alikdrone-rc2-installer.apk);
2. поместите его в `microSD:/Download/`;
3. установите Package Installer первым;
4. при сохранении ограничения перезагрузите пульт;
5. после этого установите Hub.

Package Installer не входит в Git/GPL-репозиторий AlikDrone Hub. Подробный порядок: [INSTALL.md](INSTALL.md).

## Android блокирует неизвестный источник

Нажмите «Настройки», включите «Разрешить установку из этого источника» и вернитесь назад. Проверьте, какому приложению выдаётся разрешение:

- «Файлы» — для первоначальной установки Hub с microSD;
- AlikDrone Hub — для установки приложений из каталога Hub.

Это два независимых разрешения. Окончательную установку всегда подтверждает пользователь в системном окне Android.

## «Приложение не установлено»

1. Убедитесь, что открыт файл с расширением `.apk`, а не ZIP с исходниками.
2. Скачайте APK повторно и сверьте SHA-256 со значением в GitHub Release.
3. Если раньше был установлен Hub с другой подписью или требуется откат, отключите Taskbar и удалите текущий Hub через системные настройки Android.
4. Установите нужную версию заново.

Удаление Hub сбрасывает его локальные настройки и журнал. Установленные сторонние приложения и APK в общей папке `Download` автоматически не удаляются.

## APK не виден на microSD

- проверьте путь: файл должен лежать в `microSD:/Download/`;
- убедитесь, что APK не остался внутри ZIP-архива;
- извлеките и снова вставьте карту, затем откройте её через уведомление «Обзор»;
- если карта не определяется, сохраните её содержимое и отформатируйте карту средствами пульта — форматирование удаляет все файлы.

## Каталог не загружается

1. Проверьте подключение пульта к интернету и свободное место.
2. Убедитесь, что системный Download Manager не отключён.
3. Перезапустите Hub и повторите загрузку.
4. Если ошибка повторяется, приложите к issue точный текст сообщения и безопасный отчёт поддержки.

Для Discord используется XAPK со split-пакетами. Устанавливайте его из Hub: обычный файловый менеджер не обязан уметь устанавливать XAPK.

## Приложение установлено, но не появилось в Hub или Taskbar

Обновите список приложений или перезапустите Hub. В Taskbar показываются только приложения с запускаемым экраном Android; системный компонент без иконки запуска там не появится.

Если иконка скрыта, нажмите значок глаза рядом с приложением в списке Hub.

## Taskbar не появляется

1. Включите Taskbar на главном экране Hub.
2. Разрешите Hub показываться поверх других приложений.
3. Вернитесь в Hub и включите Taskbar повторно.
4. При необходимости перезагрузите пульт.

Taskbar следует отключать во время полёта и обновления прошивки.

## Откат или полное удаление

1. Откройте Hub и отключите Taskbar.
2. Перейдите в системные настройки Android: `Приложения → AlikDrone Hub → Удалить`.
3. Для отката установите APK нужной версии из GitHub Releases. Android может потребовать предварительное удаление более новой версии.

Удаление Hub не откатывает отдельно установленный Package Installer. Не удаляйте системный компонент вслепую; для его восстановления используйте штатные средства пульта и [основную инструкцию](https://alik-drone.ru/hub/).

## Нужна помощь

Следуйте [SUPPORT.md](../SUPPORT.md). Не публикуйте серийные номера, координаты, SSID, IP/MAC, токены, личные файлы или содержимое логов.
